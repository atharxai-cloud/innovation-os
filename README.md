# Innovation OS

**نظام تشغيل الابتكار والبحث والتطوير**

Innovation OS is an Arabic-first / English-native SaaS for turning an unstructured idea into an evidence-based, testable innovation project.

## Product North Star
> What should this innovator do next — and why?

## MVP Journey
IDEA → UNDERSTAND → EVIDENCE → PRIOR ART → GAP → EXPERIMENT

Powered by:
- Project State Machine
- Structured Project Knowledge Model
- Project Brain
- Specialist AI Agents
- Innovation Navigator

## Architecture
Target stack:
- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase Auth / PostgreSQL / Storage / RLS
- pgvector + PostgreSQL FTS
- Modular Monolith

## Engineering Rules
- GitHub is the canonical source of code.
- No production changes without version-controlled migrations.
- Every exposed table requires explicit grants, RLS, policies, constraints, and indexes as applicable.
- Cross-workspace isolation failures block release.
- No fabricated research sources or patentability verdicts.
- MVP scope is governed by the approved PRD.

Technical design and foundation phase.
